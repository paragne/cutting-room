# Decisions

Append only. One line per decision, with the reason.

- 2026-10-07: Standalone web app, not an Immich plugin. Immich plugins are server-side workflow WASM modules with no UI hook.
- 2026-10-07: SvelteKit + adapter-node. Immich's own web client is SvelteKit; boring choice, not a learning entry.
- 2026-10-07: Immich API key held server-side, browser gets a session cookie. Avoids keys in the bundle or localStorage and avoids CORS changes on Immich.
- 2026-10-07: Single user, one API key from env, app password stored as an argon2id hash in env. Anyone who reaches the app can trash the library, so the app gates itself.
- 2026-10-07: Left swipe trashes immediately in Immich, no pending pile. Immich trash is the safety net; undo restores from trash.
- 2026-10-07: Never force-delete, and refuse to run if Immich trash is disabled. Protects against permanent loss.
- 2026-10-07: Review state in local SQLite (better-sqlite3), not tags in Immich. Keeps the library clean and the query local.
- 2026-10-07: License AGPL-3.0-only. @immich/sdk is AGPL-3.0, and this is a network-served app that bundles it.
- 2026-10-07: Swipe gestures hand-written with pointer events. Small code, no dependency.
- 2026-10-07: On this day uses date-range search per past year instead of Immich memories. Works even if memory generation is off.
- 2026-10-07: Project named cutting-room. Film term for where rejected footage goes; "sift" collided with an existing self-hosted app.
- 2026-10-07: Impeccable skill files are gitignored and installed per container. Third-party code, 18 MB binary, not ours to vendor.
- 2026-10-08: Stay on SvelteKit 2 (2.70.3) for now. Stack specifies it; Kit 3 was one week old at scaffold time.
- 2026-10-08: Pin Immich server v3.2.0 and @immich/sdk 3.2.0 exactly. SDK must match server; bump together.
- 2026-10-08: Check server trash enabled before every trash call, not only at startup. With trash disabled, non-force deletes are purged at the next nightly job.
- 2026-10-08: Never call resolveDuplicates. It force-deletes when trash is disabled; Compare trashes with deleteAssets instead.
- 2026-10-08: Immich SDK is initialized on first call, not at import. Build analysis imports server modules and must not need env.
- 2026-10-08: Startup check runs in the hooks.server.ts `init` hook, skipped when building. In production a bad config exits the process before it listens.
- 2026-10-08: immich.ts search wrappers always set trashedAt null and timeline visibility, and do not accept `or`. Callers cannot widen the filter.
- 2026-10-08: Startup check makes one authenticated call (asset statistics). Version and features are public, so they do not prove the key works.
- 2026-10-08: Split task 4 into 4a (core) and 4b (wiring). Sessions need SQLite, so 4a brings a minimal migrations runner forward from task 5.
- 2026-10-08: Deny better-sqlite3 install script via allowScripts. It ships prebuilds for linux glibc and musl; the script only runs node-gyp when none match.
- 2026-10-08: APP_PASSWORD_HASH is the argon2id PHC string base64-encoded. Raw `$` is expanded by Vite's .env loader (even single-quoted) and by Docker Compose.
- 2026-10-08: Session tokens are 32 random bytes, stored as SHA-256 only, absolute 30-day expiry. No sliding renewal; one user re-logs monthly.
- 2026-10-08: Login rate limit is in memory, per IP, 5 failures per 15 minutes. Restart resets it, which gains an attacker nothing over waiting.
- 2026-10-08: Migrations are bundled with import.meta.glob and tracked with PRAGMA user_version. No migrations table, no files read at runtime.
- 2026-10-08: Dev server binds 127.0.0.1, not the default IPv6 loopback, so VS Code port forwarding reaches it. Never bound to the LAN.
- 2026-10-08: Origin check covers every method except GET and HEAD, and a missing Origin is refused. Kit's built-in check only covers form content types.
- 2026-10-08: Referrer-Policy is same-origin, not no-referrer. Under no-referrer browsers send `Origin: null` on same-origin form posts, which the Origin check refuses.
- 2026-10-08: CSP via kit.csp in auto mode, so Kit adds nonces for its own inline scripts. Other headers are set in the handle hook, which returns refusals as responses so they get the headers too.
- 2026-10-08: Unauthenticated /api requests get 401 JSON; other paths redirect to /login. A fetch caller can't use a redirect to a login page.
- 2026-10-08: One decisions row per asset; a new decision replaces it and undo deletes it. The queue only needs "reviewed or not", and replacing keeps stats from double counting.
- 2026-10-08: daily_stats counters are updated in the same transaction as decisions, so home screen stats and streak never scan the decisions table.
- 2026-10-08: Trashed file size is stored on the decision at trash time, so "space trashed" needs no Immich call per asset.
- 2026-10-08: The decision's day is passed in by the caller and stored on the row, so undo decrements the day it was counted on, not today.
- 2026-10-08: Media is one route, /media/[id]/[kind], with kind checked against thumbnail, preview, video. Unknown kinds (fullsize, original) return 404 before any Immich call.
- 2026-10-08: Media fetch uses redirect: 'error' and Accept-Encoding: identity. Fullsize redirects to the original, and decompression would make the passed Content-Length wrong.
- 2026-10-08: Only one bytes= range is forwarded; anything else is dropped and the full file served. Immich 404 maps to 404; other errors and non-image/video bodies map to an empty 502.
- 2026-10-08: Queue cursor is the last takenAt plus the ids already passed at that time, queried with gte (asc) or lt t+1ms (desc). Offset paging skips assets after trashing, takenAt alone skips or repeats ties, and the API truncates times to ms.
- 2026-10-08: Reviewed assets are dropped from Immich results locally against the decisions table, fetching 200 per search for a page of 20. Immich cannot filter by our ids.
- 2026-10-08: Deciding on an asset that already has a decision returns 409; undo first. Re-deciding a trashed asset as keep would leave it in Immich trash.
- 2026-10-08: The client sends its local day; the server accepts it only within one day of its UTC date. Any real time zone falls inside that.
- 2026-10-08: Trash calls Immich before writing the decision, and undo restores before deleting it, so an Immich failure leaves the DB unchanged. Undo with restore count 0 returns 409 and keeps the decision.
- 2026-10-08: `getAsset` returns null on Immich 400 or 404 (verified live), so Immich error handling stays inside `immich.ts`.
- 2026-10-09: Visual world is "the edit suite at 2am" (dark NLE panels, amber timecode, session timeline as the signature move), pinned by the user over the rolled directions. Controls stay standard web controls so it never becomes a costume of an editor.
- 2026-10-09: DESIGN.md is written now as a seed and regenerated from the built swipe screen at the end of task 9. A spec written before code drifts from it.
- 2026-10-09: Shuffle all is the default mode; photoshoot shuffle is a separate mode. Users said random feed is the core loop.
- 2026-10-09: UI copy is playful, but buttons stay literal (Trash, Undo, Keep) so a destructive action is never ambiguous.
- 2026-10-09: The deck moves only after the server confirms a decide or undo, and blocks input meanwhile. Optimistic advance would need rollback across several in-flight requests; one Immich trash call on the LAN is short enough to hide behind the swipe animation.
- 2026-10-09: Swipe release decides on 30% of card width, or a fling of 0.5 px/ms from at least 24px, measured over the last 80ms. Starting values, tuned in 9b.
- 2026-10-09: Asset details come from a separate `GET /api/asset/[id]` fetched only while the Details panel is open, returning six chosen fields. Putting them in the queue DTO would cost an Immich `getAssetInfo` per queued asset.
- 2026-10-09: Card styles set transforms through the `style:` directive (CSSOM), not inline style attributes, because `style-src 'self'` blocks the latter.
- 2026-10-09: Keep and trash timeline blocks share one shape and differ by color only, at the user's request.
- 2026-10-10: Login uses the shared theme tokens and imports `theme.css` itself, since it does not render under the swipe page. Its error text stays `--cut` for now, flagged as a conflict with Two Signals.
- 2026-10-10: Favorite is a keep with `favorite: true` on `/api/decide`, not its own endpoint, so the Immich call and the decision succeed or fail together.
- 2026-10-10: `decisions.favorite` is 1 only when we turned the flag on. Undo clears it only then, so undoing never removes a favorite the user set in Immich.
- 2026-10-10: Videos autoplay muted and loop; sound is opt in through a button, because browsers block unmuted autoplay. The choice lasts for the session.
- 2026-10-10: Share is split out as task 10c, and GIF autoplay as 10b. Share needs an original-file proxy kind and the API key's download permission, which is more than one change.
- 2026-10-10: The API key now has asset.download, and the proxy serves an `original` kind (direct path, never `fullsize`). GIFs play from it because Immich previews are stills; share (10c) reuses it.
- 2026-10-10: Share sits in the Details summary row and fetches `original` as a Blob, then uses navigator.share with files or an anchor download. Sharing needs the whole file in hand, so streaming does not apply.
- 2026-10-10: Add to album is a keep with `albumId` on `/api/decide`, so the album add and the decision succeed or fail together. Immich's per-id "duplicate" result counts as success.
- 2026-10-10: Undo does not remove an asset from an album: the key has no albumAsset.delete, and an album add is not tracked per decision.
- 2026-10-10: Album hotkeys live in `settings` as JSON (digit to album id). Albums deleted in Immich are filtered out on read; the picker sets keys with a select per album.
- 2026-10-10: Shuffle uses `searchRandom` and a constant cursor, since Immich random search has no seed or paging. The Deck drops repeats, and the server ends the queue after 3 random batches that are all reviewed.
- 2026-10-10: On this day sends the client's local date as `day`, like `/api/decide`, so the server needs no timezone setting. Past years are scanned newest first, oldest first within a year, and the cursor is `year.keysetCursor`.
- 2026-10-10: `/api/queue` takes `mode` and `album`, defaulting to shuffle. The `order` param is gone: album and on this day are always oldest first.
- 2026-10-10: A photoshoot is a run of shots no more than 60 s apart, at least 3, at most 16 nearest the seed, found in a 10 minute window around a random asset. Time gap only: location adds little for bursts and needs no extra Immich data.
- 2026-10-10: Favorite and album changes are immediate Immich calls that record no decision. Only keep and trash advance a card and mark it reviewed; skip advances without a decision. This replaces the earlier rule that favorite and album counted as a keep.
- 2026-10-10: The key gains albumAsset.delete so the album sheet can toggle membership. It cannot delete albums or assets.
- 2026-10-10: Burst decisions go out one request per shot after "Keep N, trash M", and burst undo takes back only the last settled burst, client side, by undoing each shot.
- 2026-10-10: Main mode is named "Clock in" (start shift), planned as task 13b with a clocking-in animation.
- 2026-10-11: Home shows percent sorted as reviewed / (library now + trashed by us), since trashed assets leave Immich's count. Space trashed comes from `decisions.bytes`, not Immich's trash, so outside deletions and the 30 day purge do not change it. No `/api/stats`: the page load reads the DB.
- 2026-10-11: Clock in has its own queue function and response shape, `{entries}` of card or burst, since the other modes return flat `{items}`; both reuse `shootAround` so burst rules stay in one place.
- 2026-10-11: Clock in screen keeps its own queue class (`Clockin`) and shares album, favorite and share state through `AssetTools`, so `/swipe` and `/photoshoot` stay untouched until they are moved over; `ShootHeader` is reused with `title` and `home` props.
- 2026-10-11: A Clock in shift ends by estimated work (6 s per photo, a burst counts per shot, skips count), not wall time, and shows no timer, percent or count. Length comes from `SHIFT_MINUTES` (default 15) since anyone self-hosts the app.
- 2026-10-11: Burst viewer closes on a tap outside the rendered photo, computed from the image's natural size, because object-fit: contain makes the img box cover the matte.
- 2026-10-11: On this day is removed. It was the least useful mode, and it carried a year-walking cursor and a client-sent `day` for the queue.
- 2026-10-11: The app has no animation. The clock-in animation (13b(d)) was dropped before it shipped, and the card exit, razor sweep and undo slide are gone. Dragging still moves the card with the finger. Reason: the owner dislikes animation; it also removes the reduced-motion variants.
- 2026-10-11: Tone is strictly business with film-editing vocabulary. This replaces the earlier playful voice. Existing playful copy is rewritten in the rename task.
- 2026-10-11: "Clock in" is renamed "Dailies" everywhere, including the route, `mode=dailies` and file names. Film term for the day's raw footage, which is what a shift reviews.
- 2026-10-11: The top bar lives in the root layout and the layout owns the 100dvh height; pages use height 100%. One bar for every screen except /login, so pages carry no header of their own for navigation. Photoshoot title is the earliest shot rounded to the nearest minute.
- 2026-10-15: Photoshoot grid has two states. Browsing: tap opens fullscreen, controls are Skip and Trash all. Select mode (300 ms hold, or any tick, favorite or album): tap ticks, unticked shots are trashed, nothing ticked trashes all. "Keep all" is removed because Skip covers it.
- 2026-10-18: Home stats are one six-cell bar (Sorted, Trashed, Streak, Photos left, Time left, Keep rate). Photos left is library minus kept, since trashed assets already leave Immich's count; time left uses the same 6 s per photo as shifts.
- 2026-10-18: `/photoshoot` now renders `Shoot` instead of its own grid, so there is one implementation of tap, hold and select. No hover keep button: hold enters select mode and touch has no hover.
- 2026-10-18: `KeepBox` has a `large` variant for the fullscreen bar only, so the tile marker stays small over the photo.
- 2026-10-20: Custom mode years are a span (`from=2019&to=2021`) mapped to one `takenAt` range, not Immich `or` branches. `immich.ts` excludes `or` because a branch might match trashed or archived assets, and how `or` combines with other filters is untested.
- 2026-10-20: Custom mode reuses `scanPage` and shuffle, which now take a reviewed setting (`no`, `yes`, `both`), instead of a separate queue module. `reviewed=yes` can only return kept assets, since trashed ones leave Immich search.
